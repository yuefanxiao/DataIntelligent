# 03 权限模型：粒度、API key 机制与维护方

GitHub: https://github.com/yuefanxiao/DataIntelligent/issues/4
Status: closed (2026-08-11)
Resolution: 决议评论 https://github.com/yuefanxiao/DataIntelligent/issues/4#issuecomment-5252896319

Part of #1

## Question

权限模型怎么设计？

- 粒度：表级 / 列级 / 行级（行级是否要 RLS）
- 凭据机制：API key 如何生成、分发、轮换；key 绑定什么（用户/角色/范围）
- 谁维护权限：配置文件 + CLI？管理工作台（见地图 Not yet specified）？
- 与语义层的关系：权限挂在底层表还是语义实体/指标上
- 与只读从库账号的分工（PostgreSQL 侧只读账号 + 网关侧细粒度拦截如何分层）

## Resolution（2026-08-11）

权限模型 = **双表面授权 + 表级 FQN 白名单 + key→用户扁平 grants + YAML/CLI 维护**；PG 侧只保「物理不能写」。

1. **默认策略（双表面）**：业务数据面（`execute_sql`）**默认拒绝**、白名单授权；语义元数据面（`search_entities` / `get_entity` / `traverse_relations` / `get_metric_definition` / `list_enum_values`）**认证即读**——它们只读独立语义存储（schema 描述、指标口径、枚举值），不触业务数据；元数据面开卷才能支撑「发现→解析→执行」工作流，敏感防护靠业务面的表级授权（未授权表查不到）。
2. **粒度**：v1 仅**表级**授权；列级（拒绝/掩码）、行级（RLS）**后置为后续优化**（掩码需改写结果集、join 语义复杂；RLS 需主→从角色映射且无多租户诉求）。
3. **挂载点**：授权统一挂**表 FQN**（`服务.库.表`，与本体 Table 实体同一命名空间——本体即物理拓扑模型，无第二套命名）；**指标/概念授权 = 编译期展开为底层表授权**（同步管线重算，口径变更跟随），执行侧只查表级授权，不存在「指标有权但底层没权」的悬空状态。
4. **主体模型**：**key 绑定用户**（开发者身份）；授权 = 用户 → 表 FQN 的扁平 grants；v1 无角色抽象（数据结构留 `role` 字段）；用户身份稳定是 04 审计「谁查了什么」的聚合维度。
5. **凭据机制**：opaque 随机串（`dgw_` 前缀 + 32B 随机）+ **哈希存储**（sha256，明文仅创建时打印一次）；**一用户多 key**（设备/工具维度），全部解析到同一用户身份；**吊销 = 删除/置失效 + 内存缓存即时剔除**，无自动过期（过期策略归 12）。
6. **维护方**：**grants YAML + CLI**（`key create` / `key revoke`，授权变更走 Git review）；授权数据经同步管线编译进**语义存储 PG 的权限表**（复用既有实例，网关启动加载内存 + 热重载）；**管理工作台 v1 不做**（v2 候选，见地图 Not yet specified）。
7. **通配授权**：支持服务/库级通配（如 `payment-service.*`）作作者入口语法糖，编译期展开为**具体表清单**存权限表；`*` 全库**不开放**；**展开 = 快照**——**新表默认拒绝** + 管线输出「未覆盖表」告警，操作者改 grants YAML（Git review）触发重新展开确认（新表永远被动放行；告警流程归 08 细化）。
8. **SQL 解析**：`execute_sql` 用 pg_query 解析提取引用表、逐表比对授权；语法不可解析 → 拒绝；表不在本体（无授权）→ 拒绝；错误信息区分「语法错误」vs「无权限表」，让 Agent 可自我修正；解析器供 10 的 dry-run 校验复用。
9. **PG 侧分工**：PG 侧 = **一个共享只读角色**（只读强制 + `statement_timeout` + 禁 `SET ROLE`/临时表 + 行数兜底），保证「物理不能写」；表级细粒度授权、SQL 解析校验、限额、审计**全在网关侧**（per-service 账号拆分是运维负担且属重复防御，角色风暴不进 PG）。
10. **管理边界**：v1 **无管理员角色概念**——CLI 仅网关宿主机可运行（能上宿主机 = 运维者）；管理口令随 v2 控制台。
